## Prompt Original — Desenvolvimento Inicial

Atue como um desenvolvedor Python sênior especializado no ensino acadêmico de lógica de programação estruturada/procedural.

Crie um programa completo em Python utilizando `tkinter` e `tkinter.ttk` com estilo nativo de interface gráfica (`ttk.Style`).

### REGRAS OBRIGATÓRIAS (RESTRIÇÕES PEDAGÓGICAS):
1. **PARADIGMA PROCEDURAL PURO:**
   - Use ESTRITAMENTE funções procedurais e variáveis/estruturas de controle no escopo adequado (locais/globais).
   - É PROIBIDO criar classes ou instanciar objetos personalizados (NÃO use a palavra-chave `class`).
2. **USO DE ATALHOS, FUNÇÕES NATIVAS E BIBLIOTECAS:**
   - O uso de funções nativas de alto nível (ex: `sum()`, `max()`, `min()`, `len()`, `sorted()`), operadores de busca/pertencimento (`in`), fatiamento e métodos utilitários é PERMITIDO.
   - OBRIGATÓRIO: Sempre que qualquer atalho, método embutido ou função utilitária de alto nível for empregado, adicione um comentário logo acima ou ao lado explicando exatamente o que aquela função/método faz "por debaixo dos panos" e qual algoritmo tradicional ele substitui.
3. **ESTRUTURAS DE BÖHM-JACOPINI E COMENTÁRIOS GERAIS:**
   - O fluxo principal do código deve evidenciar as três estruturas de controle fundamentais: **Sequência**, **Seleção** (decisões condicionais) e **Repetição** (iterações).
   - Comente os blocos estruturais destacando seu papel pedagógico no fluxo do programa.

## Prompt de Evolução — Transformação em Sistema Completo

Você é uma IA responsável por auxiliar no desenvolvimento, aprimoramento, organização e manutenção de um projeto acadêmico desenvolvido em **Python + Tkinter**.

O projeto é um sistema de **controle e análise de notas de alunos**.

O código atual já possui uma implementação funcional. Portanto, **não desenvolva um projeto completamente diferente**. Analise o que já existe e evolua o sistema preservando suas funcionalidades úteis.

### Objetivo Principal
Transformar o sistema atual em uma aplicação de controle de notas mais **completa, funcional, organizada e visualmente profissional**, mantendo a simplicidade necessária para um projeto acadêmico.

### Requisitos-chave implementados:
- Configuração dinâmica da turma (alunos, avaliações, média mínima)
- CRUD completo de alunos (adicionar, editar, remover, consultar)
- Dashboard com indicadores reais
- Análises da turma (geral, por avaliação, individual)
- Interface moderna com abas, cards, tabelas com scroll
- Validação robusta e feedback ao usuário
- Consistência de dados entre todas as áreas
- Paradigma procedural puro mantido
