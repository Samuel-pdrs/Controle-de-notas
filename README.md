# 📚 Sistema de Controle de Notas - UEMG Carangola

Sistema acadêmico desenvolvido em **Python** com interface gráfica **Tkinter/ttk** para controle, gerenciamento e análise de notas de alunos, seguindo o paradigma de programação procedural estruturada.

## 🎯 Objetivo

O projeto tem como objetivo facilitar o registro e acompanhamento do desempenho da turma, permitindo configurar quantidade de alunos, quantidade de avaliações e média mínima para aprovação. O sistema calcula médias, situações acadêmicas e indicadores reais a partir dos dados cadastrados.

## ✨ Funcionalidades Implementadas

* ⚙️ Configuração da turma: quantidade máxima de alunos, avaliações e média mínima
* 👤 Cadastro de alunos com nome e notas dinâmicas
* ↕️ Rolagem vertical na área de notas para acessar todas as avaliações configuradas
* ✏️ Edição de alunos e alteração de notas
* 🗑️ Remoção de aluno com confirmação
* 🔎 Pesquisa/filtro por nome na tabela
* 📝 Validação de entrada (campos obrigatórios, números inválidos, limites 0-10)
* 📊 Cálculo automático de médias individuais
* ✅ Determinação da situação: APROVADO ou REPROVADO conforme média mínima configurada
* 📋 Tabela de alunos com rolagem vertical e horizontal
* 🎨 Interface moderna com cards, ícones, paleta de cores e estado vazio orientativo
* 📈 Dashboard com alunos cadastrados, média da turma, aprovados e reprovados
* 📉 Análises da turma: maior/menor média, percentuais, capacidade e quantidade de avaliações
* 🧮 Análise por avaliação: média da turma em cada avaliação
* 👁️ Consulta individual: notas, média, situação e alerta de desempenho
* 🧹 Limpeza de dados com confirmação

## 🛠️ Tecnologias

* **Python 3.x**
* **tkinter** / **tkinter.ttk** (interface gráfica nativa)

## ▶️ Como executar

Execute o arquivo principal:

```bash
py main.py
```

Caso o comando `py` não esteja disponível, utilize o comando Python configurado no sistema.

## 📌 Sobre o projeto

Este projeto foi desenvolvido com foco em **funcionalidade, organização, usabilidade e prática de programação procedural estruturada** (sem uso de classes), seguindo as estruturas de controle fundamentais de Böhm-Jacopini (Sequência, Seleção e Repetição).
