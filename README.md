# 📚 Controle de Notas de Alunos

Sistema desenvolvido em **Python** para auxiliar no controle e gerenciamento das notas de alunos de forma simples e organizada.

## 🎯 Objetivo

O projeto tem como objetivo facilitar o registro e acompanhamento do desempenho dos alunos, permitindo organizar suas notas e visualizar suas respectivas médias e situações acadêmicas.

## ✨ Funcionalidades

* 👤 Cadastro de alunos
* 📝 Registro de notas
* 📊 Cálculo de médias
* ✅ Verificação da situação do aluno
* 🔎 Consulta de informações
* ✏️ Atualização de dados
* 🗑️ Remoção de alunos

## 🛠️ Tecnologia

* **Python**
