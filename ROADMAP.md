# ROADMAP.md

O roadmap reflete a evolução do projeto acadêmico.

## Concluído
- [x] Interface gráfica com `tkinter`/`ttk` para entrada de dados de alunos.
- [x] Configuração dinâmica da turma (quantidade de alunos, avaliações, média mínima).
- [x] Validação de entrada de dados (campos vazios, formatos inválidos, limites de nota).
- [x] Cálculo automático de médias individuais.
- [x] Definição de situação (Aprovado/Reprovado) com critério configurável.
- [x] CRUD completo de alunos: adicionar, editar, remover, consultar.
- [x] Exibição de resultados em tabela (`Treeview`) com busca/filtro.
- [x] Dashboard com cards de indicadores (alunos, média, aprovados, reprovados).
- [x] Análises da turma: média geral, maior/menor média, percentuais, capacidade.
- [x] Análise por avaliação: média da turma em cada avaliação.
- [x] Consulta individual do aluno: notas, média, situação, alerta.
- [x] Funcionalidade de limpeza de dados (individual e total).
- [x] Ajuste automático de notas ao alterar quantidade de avaliações.
- [x] Feedback visual e mensagens de confirmação/erro amigáveis.
- [x] Redesign visual com paleta moderna, hierarquia tipográfica, cards, ícones e estado vazio da tabela.
- [x] Rolagem vertical funcional na área de notas, incluindo suporte à roda do mouse.
- [x] Rolagem vertical em tabelas de análise e consulta individual.

## Em desenvolvimento
- Nenhuma funcionalidade está atualmente em desenvolvimento parcial.

## Planejado
- [ ] Persistência de dados (salvamento em arquivo CSV ou banco SQLite).
- [ ] Exportação de resultados para formato PDF ou Excel.
- [ ] Pesos diferenciados por avaliação.
- [ ] Sistema de recuperação / exame final.
- [ ] Controle de frequência.
- [ ] Testes automatizados para validações de regra de negócio.
- [ ] Melhorias de acessibilidade (atalhos de teclado, leitores de tela).
